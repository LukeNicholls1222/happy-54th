# SUPER PAPA 54

お父さんの誕生日（10月2日）用のページ。初期マリオ風のドット絵。

1. WORLD 10-2：お父さんが自動で走る横スクロール。タップでジャンプ、長押しで高く跳ぶ。
   マウンテンバイク → サーフィン → スノーボード → ゴルフと乗り物と景色が変わる。
   ラブラドールのライダーはずっと一緒に走る。家族も種目ごとに服装が変わる。コインは年齢の数（54枚）。
   ？ブロックから家族が出てきて後ろにつく。ほねのブロックを取るとライダーがコインを集めてくる。
2. グリーンでパット。メーターが緑のときにタップするとカップイン。
3. ろうそく（54本）→ 年齢クイズ → メッセージ

- 文面、呼び方、犬の名前、家族のひとことは `config.js`（日本語と英語の両方）
- 英語はタイトルの ENGLISH ボタンか `?lang=en`。選んだ言語は覚えておく
- 家族の見た目は `js/world.js` の `FAMILY`、ステージは `js/run.js`
- ライブラリなし。`index.html` を開けば動く
- 動作確認用に `?scene=run` / `?scene=candles` / `?scene=quiz` / `?scene=end` で途中から開ける
